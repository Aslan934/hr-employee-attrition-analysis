# HR Employee Attrition Analysis

A data analysis project focused on understanding employee attrition and identifying factors associated with employee turnover.

## Project Overview

This project analyzes a 10,000-record HR dataset with 26 variables. The analysis covers data cleaning, exploratory data analysis, attrition rates, employee characteristics, income, satisfaction, workload, tenure, and statistical relationships.

## Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook / Google Colab
- Statistical analysis

## Analysis Areas

- Data overview and cleaning
- Overall employee attrition
- Attrition by department and job role
- Overtime and attrition
- Employee demographic characteristics
- Income and attrition
- Job and work-environment satisfaction
- Workload and absenteeism
- Tenure and promotion factors
- Employee group comparisons
- Chi-square statistical testing
- Correlation analysis
- Business recommendations

## Dataset

The notebook uses `employee_attrition_dataset_10000.csv`. Place the CSV inside the `data/` directory before running the notebook.

## How to Run

1. Clone the repository.
2. Install the required Python packages.
3. Place the dataset in `data/`.
4. Open `notebooks/hr_analysis.ipynb` in Jupyter Notebook, JupyterLab, or Google Colab.
5. Run the cells sequentially.

See `requirements.txt` for the Python dependencies.
